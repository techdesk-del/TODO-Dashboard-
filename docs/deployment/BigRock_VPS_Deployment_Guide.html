Architecture Decision — Why PM2 + Reverse Proxy (Not cPanel Phusion Passenger)
Do not use cPanel's built-in "Setup Node.js App" (Phusion Passenger) for this platform. Passenger buffers and terminates long-lived Server-Sent Events (/api/realtime) and conflicts with Next.js 15 standalone builds. Run Next.js on 127.0.0.1:3000 under PM2 + systemd (survives crashes and VPS reboots) and proxy HTTPS traffic through cPanel Apache with SSE packet flushing enabled.

STEP 6

Start & Persist App with PM2 + systemd

Create /var/www/urbangaon-todo/ecosystem.config.js:

module.exports = {
  apps: [{
    name: 'urbangaon-todo',
    cwd: '/var/www/urbangaon-todo/.next/standalone',
    script: 'server.js',
    instances: 1, // Single instance keeps in-memory SSE EventEmitter coherent
    exec_mode: 'fork',
    max_memory_restart: '900M',
    env: { NODE_ENV: 'production', PORT: 3000, HOSTNAME: '127.0.0.1' },
  }],
};
pm2 start /var/www/urbangaon-todo/ecosystem.config.js
pm2 save
pm2 startup systemd   # Execute the exact systemd command PM2 outputs
STEP 7

Configure cPanel Apache Reverse Proxy (SSE Real-Time Enabled)

Never edit httpd.conf directly. Use cPanel's userdata include path:

mkdir -p /etc/apache2/conf.d/userdata/ssl/2_4/ugtodo/todo.urbangaon.com
cat <<'EOF' > /etc/apache2/conf.d/userdata/ssl/2_4/ugtodo/todo.urbangaon.com/nextjs.conf
ProxyPreserveHost On
ProxyRequests Off

# Critical: Disable buffering for Real-Time SSE (/api/realtime)
ProxyPass /api/realtime http://127.0.0.1:3000/api/realtime flushpackets=on retry=0 timeout=60
ProxyPassReverse /api/realtime http://127.0.0.1:3000/api/realtime

ProxyPass / http://127.0.0.1:3000/
ProxyPassReverse / http://127.0.0.1:3000/
RequestHeader set X-Forwarded-Proto "https"
EOF

# Force HTTP -> HTTPS redirect
mkdir -p /etc/apache2/conf.d/userdata/std/2_4/ugtodo/todo.urbangaon.com
cat <<'EOF' > /etc/apache2/conf.d/userdata/std/2_4/ugtodo/todo.urbangaon.com/redirect.conf
RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
EOF

/usr/local/cpanel/scripts/rebuildhttpdconf
/usr/local/cpanel/scripts/restartsrv_httpd
