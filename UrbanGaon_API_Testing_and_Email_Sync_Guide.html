2. Step-by-Step API Testing Protocols

POST /api/auth/login

Test 1: Executive 2FA Authentication (Synced with OTP Email)

Executive accounts require a two-step verification cycle. When Step 1 credentials pass, the server dispatches a real-time 6-digit OTP to techdesk@urbangaon.com.

Step 1: Send Credentials 
POST {{baseUrl}}/api/auth/login
Content-Type: application/json

{
  "email": "ceo@urbangaon.com",
  "password": "admin"
}
Expected Step 1 Response (2FA Prompt): 
{
  "success": false,
  "requires2FA": true,
  "role": "SUPER_ADMIN",
  "message": "Two-step verification required. A 6-digit verification code has been dispatched in real time to techdesk@urbangaon.com."
}
Step 2: Submit with 2FA Code

Supply the 6-digit OTP received in email, or use the Founder development bypass code 123456:

POST {{baseUrl}}/api/auth/login
Content-Type: application/json

{
  "email": "ceo@urbangaon.com",
  "password": "admin",
  "twoFactorCode": "123456"
}
Success Response: Returns JWT Bearer token and sets secure HTTP-only cookie urbangaon_auth_token. Copy this token into your Postman collection variable {{authToken}}.
POST /api/tasks

Test 2: Create Deliverable (Synced with Task Assignment Email)

Creates an official task and dispatches an immediate assignment email via Gmail SMTP to all designated assignees. 

POST {{baseUrl}}/api/tasks
Content-Type: application/json
Authorization: Bearer {{authToken}}

{
  "title": "Vendor payment verification and ledger reconciliation",
  "scheduledDate": "2026-11-06",
  "time": "05:00 PM",
  "priority": "HIGH",
  "department": "Procurement & Materials",
  "project": "Jaipur Expansion Project",
  "location": "Jaipur Corporate Office",
  "assignees": [
    {
      "id": "mem-2",
      "name": "Ravindra Singh",
      "email": "ravindra@urbangaon.com",
      "department": "Procurement & Materials",
      "status": "Not Started"
    }
  ],
  "creator": {
    "id": "mem-ops-admin",
    "name": "Operations Admin",
    "email": "ops@urbangaon.com",
    "role": "ADMIN"
  }
}

✓ Verification: Inspect GET /api/notifications/email-logs to see the recorded dispatch with subject "New Deliverable Assigned: Vendor payment verification...".

4. Postman Environment Setup & UI Verification

Importing the Preconfigured Collection

  1. Open Postman and click Import in the top-left corner.
  2. Choose the file located at: d:\TODO Dashboard New updated Version\postman_collection.json.
  3. The collection "UrbanGaon AI Todo Platform API" will appear in your sidebar with 8 pre-built folders.
